## ADDED Requirements

### Requirement: 練習開始前に質問難易度を選択できる
システムは、面接練習モードの質問生成を開始する前に、ユーザーが難易度（初級/中級/上級）を選択できるようにしなければならない（SHALL）。難易度が選択されるまで、質問生成は開始されない。

#### Scenario: 難易度未選択では生成を開始できない
- **WHEN** ユーザーが面接練習ページを開き、まだ難易度を選択していない
- **THEN** 質問生成の開始操作（生成ボタン）は無効化されているか、選択を促す案内が表示される

#### Scenario: 難易度を選択すると生成を開始できる
- **WHEN** ユーザーが初級・中級・上級のいずれかを選択する
- **THEN** 質問生成の開始操作が有効になる

### Requirement: 選択した難易度に応じて質問セットを生成する
システムは、選択された難易度に応じて複雑さ・深掘り度が異なる模擬面接質問を、設定済みの AI プロバイダーを使って1回の生成につき5問生成しなければならない（SHALL）。生成には練習質問生成専用のシステムプロンプトを用い、会話履歴は含めない。

#### Scenario: 初級を選択すると基本的な質問が生成される
- **WHEN** ユーザーが難易度「初級」を選択して生成を開始する
- **THEN** 自己紹介・経歴確認など基本的な質問を主とした5問が生成される

#### Scenario: 中級を選択すると経験の深掘り質問が生成される
- **WHEN** ユーザーが難易度「中級」を選択して生成を開始する
- **THEN** 技術経験や実績の深掘りを含む質問を主とした5問が生成される

#### Scenario: 上級を選択すると高度な質問が生成される
- **WHEN** ユーザーが難易度「上級」を選択して生成を開始する
- **THEN** 高度な技術的判断や意思決定の理由を問う質問を主とした5問が生成される

#### Scenario: AIプロバイダー未設定時は生成を行わない
- **WHEN** AIプロバイダーが設定されておらず、かつ Pluely API が無効の状態でユーザーが生成を試みる
- **THEN** 「AIプロバイダーが選択されていません」という案内が表示され、生成リクエストは送信されない

### Requirement: 生成した質問セットを一覧表示する
システムは、生成された質問セットを1問ずつ、選択された難易度とともに画面上に一覧表示しなければならない（SHALL）。

#### Scenario: 生成完了後に質問一覧が表示される
- **WHEN** 質問生成リクエストが完了する
- **THEN** 生成された5問が1行ずつ一覧表示され、選択されていた難易度が併せて表示される

#### Scenario: 生成中はローディング状態を表示する
- **WHEN** 質問生成リクエストが進行中である
- **THEN** 一覧表示エリアにローディングインジケーターが表示される

#### Scenario: 出力形式が崩れた場合は生レスポンスを表示する
- **WHEN** AI プロバイダーの応答が1行1問の想定フォーマットに従っておらず質問への分割に失敗する
- **THEN** システムは分割を諦め、応答テキストをそのまま1件として表示する（情報を破棄しない）

### Requirement: 生成した質問セットをローカルに保存する
システムは、生成された質問セットをローカル SQLite に保存しなければならない（SHALL）。各質問には、所属する生成回を識別するグループ ID、難易度、質問本文、任意のカテゴリ（本要件時点では常に NULL）、生成日時を保存する。

#### Scenario: 生成完了時に質問セットが保存される
- **WHEN** 質問生成リクエストが完了し質問が一覧表示される
- **THEN** 生成された5問がそれぞれ同一のグループ IDのもと、難易度・質問本文・生成日時とともにローカル SQLite に保存される
