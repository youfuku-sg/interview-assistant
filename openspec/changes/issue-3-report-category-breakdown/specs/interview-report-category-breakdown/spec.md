## ADDED Requirements

### Requirement: 質問のカテゴリ付き記録
システムは、会話（`conversations`）に紐づく質問を、質問文と要求仕様書 §7.6 の固定カテゴリ一覧（経歴確認/技術経験/技術深掘り/転職理由/志望動機/強み/弱み/チーム開発/トラブル対応/マネジメント経験/キャリアプラン/条件確認/逆質問/その他）から選択したカテゴリとともに記録できなければならない (SHALL)。

#### Scenario: ユーザーが質問を手動で記録する
- **WHEN** ユーザーが会話詳細画面で質問テキストを入力し、カテゴリ一覧から1つを選択して追加操作を行う
- **THEN** その質問が当該会話に紐づく形で保存され、質問一覧に表示される

#### Scenario: カテゴリ未選択では保存できない
- **WHEN** ユーザーが質問テキストのみを入力しカテゴリを選択せずに追加操作を行う
- **THEN** システムは保存を行わず、カテゴリ選択が必要であることを示す

### Requirement: 面接後レポートでのカテゴリ内訳表示
システムは、会話詳細画面に、その会話に記録された質問のカテゴリ別件数内訳を表示しなければならない (SHALL)。

#### Scenario: 複数カテゴリの質問が記録されている場合に内訳を表示する
- **WHEN** ある会話に技術経験カテゴリの質問が2件、志望動機カテゴリの質問が1件記録されている
- **THEN** カテゴリ別内訳に「技術経験: 2件」「志望動機: 1件」が表示され、それぞれの件数と全体に対する割合が確認できる

#### Scenario: 質問が1件も記録されていない場合は空状態を表示する
- **WHEN** ある会話に質問が1件も記録されていない
- **THEN** カテゴリ内訳セクションには、質問がまだ記録されていない旨の空状態が表示され、件数0のグラフやリストは表示されない

#### Scenario: 質問一覧をカテゴリ別に確認できる
- **WHEN** ユーザーが面接後レポートの質問一覧を見る
- **THEN** 各質問にその質問が属するカテゴリが併記されている

### Requirement: レポート内容のテキストコピー
システムは、面接後レポートの質問一覧とカテゴリ内訳を、Markdown相当のプレーンテキストとしてコピーできる機能を提供しなければならない (SHALL)。

#### Scenario: レポートをテキストとしてコピーする
- **WHEN** ユーザーが面接後レポート画面でコピー操作を行う
- **THEN** 質問一覧（質問文・カテゴリ）とカテゴリ別件数内訳を含むMarkdown相当のテキストがクリップボードにコピーされる
