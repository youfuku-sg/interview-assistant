## ADDED Requirements

### Requirement: STT タイムアウト時にわかりやすいメッセージを表示する
`useSystemAudio` フックが STT リクエストの 30 秒タイムアウトによって文字起こしを失敗させたとき、UI にはタイムアウトを起こした生の例外メッセージ（例: `Speech transcription timed out (30s)`）ではなく、処理に時間がかかっている旨と考えられる原因・対処を示す平易な日本語メッセージを表示しなければならない（SHALL）。

#### Scenario: ローカル STT がタイムアウトする
- **WHEN** 選択中の STT プロバイダーへのリクエストが 30 秒以内に完了せずタイムアウトする
- **THEN** エラー表示には技術的な例外文字列ではなく、文字起こしに時間がかかっている旨とローカル STT サーバーやモデルの状態を確認するよう促す平易な日本語メッセージが表示される

### Requirement: 既知の技術的エラーをユーザー向けメッセージに変換する
STT リクエストがネットワークエラーまたは HTTP エラーステータスで失敗したとき、UI には `Network error: ...` や `HTTP 504: ...` のような生のエラー文字列ではなく、失敗の種類に応じた平易な日本語メッセージを表示しなければならない（SHALL）。

#### Scenario: ネットワークエラーで失敗する
- **WHEN** STT プロバイダーへのリクエストがネットワークエラー（`Network error: ...`）で失敗する
- **THEN** エラー表示には接続に失敗した旨を伝える平易な日本語メッセージが表示される

#### Scenario: HTTP エラーステータスで失敗する
- **WHEN** STT プロバイダーが 2xx 以外の HTTP ステータス（`HTTP <status>: ...`）を返す
- **THEN** エラー表示には STT プロバイダーからエラー応答があった旨を伝える平易な日本語メッセージが表示される

### Requirement: 未知のエラーには汎用メッセージへフォールバックする
既知のタイムアウト・ネットワークエラー・HTTP エラーのいずれのパターンにも一致しない STT エラーが発生したとき、UI には生の例外文字列の代わりに汎用的な失敗メッセージを表示しなければならない（SHALL）。

#### Scenario: 未分類のエラーが発生する
- **WHEN** STT リクエストが既知のパターンに一致しないエラーメッセージで失敗する
- **THEN** エラー表示には「文字起こしに失敗しました。しばらくしてから再度お試しください。」のような汎用的な日本語メッセージが表示される

### Requirement: デバッグ用に元のエラー内容をログへ残す
ユーザー向けメッセージへの変換を行っても、元の技術的なエラーメッセージは `console.error` へのログ出力から失われてはならない（SHALL NOT）。

#### Scenario: エラー発生時にコンソールへ元のメッセージが残る
- **WHEN** STT エラーが発生し、UI にはユーザー向けの平易なメッセージが表示される
- **THEN** ブラウザ／開発者コンソールには元の技術的なエラーメッセージが `console.error` により記録されている
