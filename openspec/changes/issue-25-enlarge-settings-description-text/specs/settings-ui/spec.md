## ADDED Requirements

### Requirement: 設定画面の各項目の説明文は読みやすいフォントサイズで表示される
設定画面(Settings, `src/pages/settings/`)は、各項目(テーマ、自動起動、アプリアイコン、常に最前面表示、チャット履歴削除)の説明文(タイトル直下のグレーの補足テキスト)を、設定画面以外の画面で使われるデフォルトの説明文フォントサイズより1段階大きいサイズで表示しなければならない(SHALL)。この拡大は設定画面に限定し、`Header` コンポーネントや `PageLayout` コンポーネントが持つデフォルトのフォントサイズ自体は変更してはならない(MUST NOT)。

#### Scenario: 設定画面を開く
- **WHEN** ユーザーが設定画面(Settings)を開く
- **THEN** ページ見出し(「設定」)直下の説明文と、各項目(テーマ、自動起動、アプリアイコン、常に最前面表示、チャット履歴削除)の見出し直下の説明文が、デフォルトの説明文サイズより1段階大きいフォントサイズで表示される

#### Scenario: 個別項目の補足説明文を確認する
- **WHEN** ユーザーが設定画面でテーマ切り替えの現在状態、または自動起動・アプリアイコン・常に最前面表示の各トグルの状態説明を確認する
- **THEN** ラベル直下の補足説明文(例:「明るい環境で見やすいライトテーマを使用しています」)が、デフォルトの説明文サイズより1段階大きいフォントサイズで表示される

#### Scenario: 設定画面以外の画面は影響を受けない
- **WHEN** ユーザーが設定画面以外の画面(ダッシュボード、チャット、音声、スクリーンショット、ショートカット、応答、Dev Space など)を開く
- **THEN** それらの画面の説明文フォントサイズは、この変更が加わる前と同じデフォルトサイズのまま表示される
