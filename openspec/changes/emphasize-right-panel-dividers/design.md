## Context

`2026-07-08-top-bar-right-panel-three-rows`（アーカイブ済み）で右エリアを3段に分割し、`border-b border-border/40` を上段・中段の下端に付与した。実装後に画面で確認すると、`border-border` トークン自体が薄いグレー系のため、さらに40%まで不透明度を下げると段の境目がほとんど視認できない。`top-bar-ui` spec の「各段の境界が視覚的に区別できる」要件を満たす程度まで強調する。

対象ファイルは `src/pages/app/index.tsx` のみ（`top-panel` / `middle-panel` / `bottom-panel` の3つの `div`）。

## Goals / Non-Goals

**Goals:**
- 上段・中段・下段の境目を、現状の `border-border/40` よりはっきり視認できるようにする
- 3段の境界表現を一貫させる（上段/中段間、中段/下段間で同じ強調度にする）

**Non-Goals:**
- カラーテーマ・デザイントークン自体の見直しは行わない（既存の `border-border` トークンを使う）
- 各パネル内部（`TranscriptionPanel` 等）のスタイル変更は行わない
- レイアウト構造（`flex-1` 配分、`data-slot` 命名）の変更は行わない

## Decisions

### 不透明度を `/40` から `/70` に引き上げる

`border-border` トークンをそのまま濃くする（100%）と、ウィンドウ全体の外枠（Cardの境界線）と同じ強さになり、内部の段区切りが外枠と紛れる可能性がある。外枠より弱く、かつ現状の`/40`よりはっきり見える中間値として `/70` を採用する。

代替案として検討したが採用しなかったもの:
- `border-border`（100%不透明）: 外枠と同じ強さになり、内部区切りと外枠の区別が付きにくくなる
- `border-2 border-border/40`: 太さを変えると段の高さ配分（`flex-1` 均等3分割）の見た目バランスを崩す懸念があり、太さではなく色の濃さで強調する方針とした

### `bottom-panel` にも上端境界線を追加する

現状 `bottom-panel` には境界線がない（Cardの外枠で代替する設計だった）。しかし外枠と中段/下段の境目は視覚的に別物のため、一貫性のために `middle-panel` と `bottom-panel` の間にも同じ強調度の境界線を追加する（`bottom-panel` に `border-t border-border/70` を付与、または `middle-panel` 側の `border-b` のみで表現するかは実装時にどちらか一方に統一する）。

## Risks / Trade-offs

- **リスク: 境界線が強すぎて圧迫感が出る** → `/70` は上限値の目安であり、実装後に実機で見た目を確認し、必要なら`/60`程度に調整する余地を残す。
- **トレードオフ: 外枠との強さの差が小さくなる** → 外枠（Cardの境界線）とは別トークン・別箇所のスタイルであるため、必要であれば外枠側は変更せず内部区切りだけを強調する現方針を維持する。
