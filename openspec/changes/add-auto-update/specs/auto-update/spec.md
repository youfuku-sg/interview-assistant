## ADDED Requirements

### Requirement: アプリ起動時に新バージョンを確認する
アプリケーションは起動時に、GitHub Releases 上の公開済み最新バージョンを非同期に確認しなければならない (SHALL)。この確認は起動処理をブロックしてはならない (SHALL NOT)。

#### Scenario: 起動時にバックグラウンドで更新確認が行われる
- **WHEN** アプリケーションを起動する
- **THEN** GitHub Releases の最新公開バージョンを確認するリクエストが非同期に送信され、アプリ本体の起動・表示は待たされない

### Requirement: 新バージョン検出時に確認ダイアログを表示する
現在のバージョンより新しい公開済みバージョンが検出された場合、アプリケーションはユーザーに更新を実行するかどうかを確認するダイアログを表示しなければならない (SHALL)。新しいバージョンが存在しない場合、ダイアログを表示してはならない (SHALL NOT)。

#### Scenario: 新バージョンが存在する場合にダイアログが出る
- **WHEN** GitHub Releases の最新公開バージョンが現在起動中のバージョンより新しい
- **THEN** 「更新しますか?」という趣旨の確認ダイアログが表示される

#### Scenario: 新バージョンが存在しない場合は何も表示されない
- **WHEN** GitHub Releases の最新公開バージョンが現在起動中のバージョン以下である
- **THEN** 更新確認ダイアログは表示されず、通常の起動が継続される

### Requirement: ユーザーの承認に基づいてのみダウンロード・インストールを行う
アプリケーションは、確認ダイアログでユーザーが更新を承認した場合にのみ新バージョンのダウンロードとインストールを開始しなければならない (SHALL)。ユーザーの明示的な承認なしに更新のダウンロードやインストールを行ってはならない (SHALL NOT)。

#### Scenario: 承認後にダウンロード・インストール・再起動が行われる
- **WHEN** ユーザーが確認ダイアログで更新を承認する
- **THEN** 新バージョンのダウンロードとインストールが行われ、完了後にアプリケーションが再起動される

#### Scenario: 拒否した場合は既存バージョンのまま起動を継続する
- **WHEN** ユーザーが確認ダイアログで更新を拒否する
- **THEN** ダウンロードやインストールは行われず、既存バージョンのままアプリケーションの起動が継続される

#### Scenario: 拒否した場合は次回起動時に再確認する
- **WHEN** ユーザーが更新を拒否したセッションの後、アプリケーションを再起動する
- **THEN** 同じ新バージョンが公開済みのままであれば、再度更新確認ダイアログが表示される

### Requirement: 更新確認の失敗は起動を妨げない
GitHub Releases への到達不可・API エラー等により更新確認が失敗した場合、アプリケーションはエラーをユーザーに表示せず、通常の起動を継続しなければならない (SHALL)。

#### Scenario: オフライン時でも通常起動する
- **WHEN** ネットワークに接続されていない状態でアプリケーションを起動する
- **THEN** 更新確認はエラーとなるが、更新エラーに関するダイアログは表示されず、アプリケーションは通常どおり起動する

### Requirement: draft の GitHub Release は更新確認の対象にならない
アプリケーションの更新確認は、GitHub Releases のうち draft 状態の Release を新バージョンとして検出してはならない (SHALL NOT)。公開(Published)済みの Release のみを検出対象とする (SHALL)。

#### Scenario: draft Release は検出されない
- **WHEN** 現在のバージョンより新しい draft 状態の GitHub Release のみが存在する
- **THEN** アプリケーションは新バージョンを検出せず、更新確認ダイアログは表示されない

#### Scenario: Release を公開すると検出される
- **WHEN** draft だった Release が Published 状態に変更される
- **THEN** 以降のアプリケーション起動時に、そのバージョンが新バージョンとして検出され、更新確認ダイアログが表示される
